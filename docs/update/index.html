Firmware Update Tool

Flash your OpenDiag adapter straight from this page — no drivers, no toolchain.

Latest release checking…

  1. Hold the button

    Press and hold the button on the OpenDiag device — keep holding it through the next step.

  2. Plug in the USB cable

    While still holding the button, connect OpenDiag to your computer's USB port. Release the button once it's plugged in.

  3. Start the update

    Your browser will ask you to pick a device:

    • Select the one called "USB JTAG/serial debug unit".
    • If it isn't listed, unplug the device and repeat steps 1 and 2.

    Your browser can't talk to serial devices. Use desktop Chrome or Edge — mobile browsers are not supported.

    This page must be served over HTTPS (or from localhost) to flash firmware.

    When the update finishes, unplug OpenDiag and plug it back in normally.

Requires desktop Chrome or Edge. Mobile browsers, Safari, and Firefox cannot access USB serial devices.
